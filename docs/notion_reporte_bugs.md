# Nova funcionalidade: Reporte de bugs no sistema

## Objetivo

O reporte de bugs foi criado para facilitar a comunicação de problemas encontrados durante o uso do sistema.

A função permite que usuários autorizados registrem erros de forma organizada, acompanhem o andamento da tratativa e recebam atualizações quando houver retorno do suporte técnico.

## Quem pode utilizar

No momento, a abertura de bugs está disponível para:

- Coordenadorias
- COVISA

As UVIS não possuem permissão para abrir bugs diretamente nesta etapa.

## Quando usar

O reporte deve ser utilizado quando houver algum problema no sistema, como:

- Tela que não abre corretamente
- Botão que não funciona
- Erro ao salvar uma informação
- Informação exibida de forma incorreta
- Mensagem de erro durante o uso
- Travamento ou falha que impeça a continuidade do trabalho

Essa função não deve ser usada para dúvidas operacionais, solicitações gerais ou pedidos de melhoria. Neste primeiro momento, o uso é exclusivo para erros no sistema.

## Como reportar um bug

1. Acesse o menu **Reportar bug**.
2. Informe um assunto claro para o problema.
3. Selecione o impacto percebido.
4. Descreva o que aconteceu.
5. Inclua prints, se houver.
6. Envie o reporte.

Após o envio, o sistema confirma que o bug foi reportado com sucesso.

## Como acompanhar

Os bugs enviados ficam disponíveis na **Caixa de bugs**.

Nessa tela é possível acompanhar:

- Bugs em aberto
- Bugs em análise
- Bugs em correção
- Bugs corrigidos
- Responsável pela tratativa, quando definido
- Atualizações enviadas pelo suporte técnico

O usuário que reportou não conversa por chat com os devs. Ele apenas acompanha as atualizações registradas na tratativa.

## Limite de bugs ativos

Cada origem possui um limite de até **3 bugs ativos** ao mesmo tempo.

Para as coordenadorias, o limite é aplicado por coordenadoria/região.

Para a COVISA, o limite é aplicado à própria conta COVISA.

Quando o limite for atingido, será necessário aguardar a conclusão de um bug ativo antes de enviar outro.

## Fluxo da tratativa

1. O usuário autorizado identifica um erro no sistema.
2. O bug é reportado.
3. O usuário recebe a confirmação de envio.
4. O bug entra na fila do suporte técnico.
5. O suporte técnico analisa e atualiza a tratativa.
6. O usuário acompanha as atualizações pela Caixa de bugs.
7. Após a correção, o suporte técnico encerra o bug.

## Boas práticas ao reportar

Para ajudar na análise, o relato deve ser claro e objetivo.

Sempre que possível, informe:

- O que estava tentando fazer
- Em qual tela o problema aconteceu
- Qual mensagem apareceu
- Se o erro acontece sempre ou apenas às vezes
- Prints da tela com o problema

Quanto mais completo for o relato, mais fácil será identificar e corrigir o problema.

## Observações importantes

- A funcionalidade é exclusiva para problemas no sistema.
- A subcategoria fica fixa como **Erro no sistema**.
- O atendimento fica direcionado ao **Suporte técnico**.
- As atualizações ficam disponíveis apenas para acompanhamento.
- O encerramento do bug é feito pelo suporte técnico após a correção.
